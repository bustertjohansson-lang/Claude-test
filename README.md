# Vroom – prototyp

Social plattform för bilar och A-traktorer (tänk Blocket möter Instagram). **Prototyp med exempeldata – inte redo för riktiga användare.**

## Filer
- `index.html` – sidans struktur
- `style.css` – mörk, responsiv design
- `app.js` – exempeldata, filter, flöde och fordonskort (ren JavaScript, inga beroenden)

## Köra lokalt
```
python3 -m http.server 8123
```
Öppna sedan http://localhost:8123
